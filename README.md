# Проект 6.5 — Разделение изотопов

Проект по электромагнетизму, Университет ИТМО.

## Описание

Численное моделирование движения однозарядных ионов с различными массами в магнитном поле и определение точек их попадания на детектор.

Программа написана на языке C.

## Запуск на macOS

1. Скачайте файл `main.c`.
2. Откройте терминал в папке с файлом.
3. Выполните команды:

```bash
clang -std=c11 -O2 main.c -o isotopes -lm
./isotopes
```

## Результаты

Программа рассчитывает траектории пяти изотопов и создаёт графики и CSV-файлы в папке `isotope_results`.
